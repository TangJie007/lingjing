# 窗口创建 

## createMainWindow 主窗口创建

简化了应用的主窗口创建逻辑，该函数类型为:

```ts
createMainWindow(
    loadURL: string, 
    config: Electron.CrossProcessExports.BrowserWindowConstructorOptions
): (
    callBack: (
        app: Electron.CrossProcessExports.App, 
        mainWindow: Electron.CrossProcessExports.BrowserWindow
    ) => void
) => void
```

```ts
if (started) { app.quit() }

const loadURL = app.isPackaged ? 
path.join(__dirname,'dist-views','index.html'):
'http://localhost:5173/'

createMainWindow(loadURL,{
  ...appConfig.shape,
  webPreferences: {
    // 加载预加载脚本
    preload: path.join(__dirname, 'preload.js'),
  }
})((appIns,browserWinIns)=>{
  // 主进程事件注册
  mainEvents(appIns,browserWinIns)
})
```
