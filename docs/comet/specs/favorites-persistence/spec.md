# favorites-persistence

收藏持久化（F7）：收藏状态与必要索引写入应用数据目录 JSON；重启后「我的收藏」与数量 hint 正确。不引入云同步与登录。

## 范围

- 扩展现有 `FavoritesView` / `onFavorite`：读写持久化层，而非仅改内存 `CATALOG`。
- 应用数据目录 JSON 为真源（可与本地库索引分文件或同文件分节）。
- 发现页、详情抽屉、本地库、收藏页的收藏切换共用同一持久化 API。

## 条款

### 持久化

- MUST：使用应用数据目录 JSON 文件保存收藏（至少：条目 id、favorite 布尔或 id 集合）；经 Tauri FS（或项目内封装）读写。
- MUST：不以 localStorage 作为唯一真源；不新增 `tauri-plugin-store`。
- MUST：切换收藏后在合理短延迟内落盘（立即或 debounce ≤ 500ms），应用正常退出不丢最近一次切换。

### UI 语义

- MUST：保留文案「已收藏 N 张壁纸 · 本地保存，无需登录」；N 来自持久化后的真实集合。
- MUST：重启应用后，已收藏项仍出现在「我的收藏」；未收藏项不出现。
- MUST：取消收藏后网格移除该卡（或空态），且落盘后重启仍为未收藏。

### 条目范围

- MUST：在线 catalog 项与本地库项只要暴露收藏控件，均写入同一收藏模型（本地项用稳定本地 id）。
- MUST：无登录门闸。

## 验收

| ID | 条款 | 验证方式 |
|----|------|----------|
| FP-1 | 存在应用数据目录 JSON 读写路径 | 静态读 |
| FP-2 | 非 localStorage 唯一真源、无 plugin-store | 静态读 |
| FP-3 | 重启后收藏集合保持 | 手动 |
| FP-4 | hint N 与真实收藏数一致 | 手动 |
| FP-5 | 发现/抽屉/收藏页切换同源 | 静态读 |
