# sample-media

发现页示例媒体（支撑 D4 / A9）：为前若干 catalog 条目绑定包内可播放文件，使「设为壁纸」在无用户导入时也能演示引擎。

## 范围

- 在 `public/` 或 Tauri `resources` 中放置 ≥6 个示例文件（视频与至少一种动图/静图组合均可）。
- `catalog.ts`（或并列映射表）为前 ≥6 条提供 `mediaSrc` / `mediaType` 字段。
- 构建产物包含这些资源。

## 条款

- MUST：至少 6 条发现页卡片绑定可解析的包内媒体 URI。
- MUST：绑定项「设为壁纸」走真实引擎并显示对应画面。
- MUST：未绑定项不假装成功（见 wallpaper-engine）。
- MUST：示例媒体体积保持合理（单文件建议 < 5MB，总包增量可控）；可用短循环短片。

## 验收

| ID | 条款 | 验证方式 |
|----|------|----------|
| SM-1 | ≥6 条 catalog 含媒体绑定 | 静态读 |
| SM-2 | 资源存在于构建可访问路径 | 静态读 + 构建产物 |
| SM-3 | 绑定项设壁纸可播 | 手动 |
