#  进程间通信

::: tip
虽然electron的文档对进程间的通信，讲的已经非常详细，但是实际开发中和使用中还是会有很多困惑。

**本节仅仅只讲安全模式下的通信**。
:::

## 单向通信和双向通信

### 单向通信

1. 主进程向渲染进程进行通信
  
  ```ts
  // 主进程发送消息
  win.webContents.send(channel: string, ...args: any[])
  // 渲染渲染进程监听消息，通常会将该逻辑放在预加载脚本当中
  ipcRenderer.addListener(
    channel: string, 
    listener: (event: Electron.IpcRendererEvent, ...args: any[]) => void
  )
  // 也可以使用on去监听

  ```
