# 灵境（LingScape）动态桌面实现原理

> 文档版本：1.1.0 | 对应代码版本：Phase 2（壁纸引擎 + MPV 嵌入）| 更新日期：2026-06-13

---

## 一、架构总览

灵境的动态桌面系统采用 **应用主界面 + 系统桌面层嵌入** 的分离架构：

```
┌──────────────────────────────────────────────────────────────┐
│  其他应用窗口                                                  │
├──────────────────────────────────────────────────────────────┤
│  桌面图标层（SHELLDLL_DefView + SysListView32）                │  ← Windows Shell 管理
├──────────────────────────────────────────────────────────────┤
│  视频壁纸层（MPV 窗口，--wid 嵌入 WorkerW / shell_host）      │  ← 动态壁纸渲染
├──────────────────────────────────────────────────────────────┤
│  静态桌面背景 / 第三方桌面工具覆盖层（如腾讯桌面整理）           │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│  灵境主窗口（WebView）                                         │  ← 用户交互层
│  · 壁纸库浏览、AI 创作、设置                                   │
│  · 与壁纸渲染进程解耦，关闭主窗口不影响已应用的壁纸              │
└──────────────────────────────────────────────────────────────┘
```

### 关键设计决策

| 决策 | 说明 |
|------|------|
| **静态壁纸走 Windows API** | 图片壁纸用 `SystemParametersInfoW(SPI_SETDESKWALLPAPER)` 设置，零 CPU 渲染开销。 |
| **视频壁纸走 MPV + `--wid`** | Windows 原生不支持视频桌面背景。参考 Lively Wallpaper / weebp，将 MPV 子窗口嵌入 Explorer 桌面层，而非自建全屏 WebView。 |
| **多屏每显示器一个 MPV 实例** | 枚举所有显示器，每个显示器启动独立 MPV 进程，通过 `--geometry` 铺满对应区域。 |
| **Rust 管理嵌入，MPV 管理解码** | 窗口探测、SetParent、Z-order 由 `desktop_core.rs` 完成；视频解码与循环播放由 MPV 负责（`--loop-file=inf --hwdec=auto-safe`）。 |
| **第三方桌面整理** | 全屏 `TXMiniSkin`（≥70% 屏）临时隐藏，退出壁纸后恢复；小栅栏不隐藏 |
| **同类动态壁纸共存** | 启动时隐藏飞火/Lively 等竞争播放窗口，退出时恢复 |
| **WebView 桌面播放器保留备用** | `desktop-player` 窗口仍预创建，供未来 HTML/GIF 壁纸；当前视频路径会隐藏该窗口。 |

## 二、Windows 桌面层结构

Explorer 的桌面并非单一窗口，而是一组嵌套的 HWND。灵境需要找到正确的「壁纸宿主」和「图标层」，才能把 MPV 放在图标之下、背景之上。

### 2.1 典型窗口树（Win10 / Win11 双屏）

```
Progman (0x101f8)
├── WorkerW (0x10618)          ← 壁纸 WorkerW，3840×1080（虚拟桌面尺寸）
├── WorkerW                    ← 图标 WorkerW（部分系统版本）
│   └── SHELLDLL_DefView
│       └── SysListView32      ← 桌面图标列表
└── TXMiniSkin（小窗口）        ← 腾讯栅栏等 UI

shell_host（顶层 WorkerW 或 Progman）
└── SHELLDLL_DefView (0x10614)
    ├── SysListView32
    └── TXMiniSkin (全屏皮肤)   ← 腾讯桌面美化，会遮挡壁纸
```

### 2.2 Z-order（正常状态）

```
从高到低：
  桌面图标（SysListView32）
  MPV 播放窗口（嵌入 WorkerW 或压在 DefView 下方）
  壁纸 WorkerW / 静态背景
```

### 2.3 探测与准备（`desktop_core.rs`）

1. 向 `Progman` / `shell_host` 发送 `SendMessageW(0x052C, 0xD, 0)`，触发 Shell 创建壁纸 `WorkerW`
2. 调用 `detect_desktop_layer()` 收集 `DesktopLayer` 结构：

| 字段 | 含义 |
|------|------|
| `progman` | Progman 窗口句柄 |
| `shell_host` | 含 `SHELLDLL_DefView` 的宿主（Progman 或 WorkerW） |
| `shell_view` | `SHELLDLL_DefView` 句柄 |
| `worker_w` | 壁纸专用 WorkerW |
| `is_raised` | Win11 24H2+ Raised Desktop 模式 |

### 2.4 嵌入模式（`AttachMode`）

`resolve_attach_mode()` 按优先级选择：

| 模式 | 条件 | MPV 嵌入目标 |
|------|------|-------------|
| **ClassicWorkerW**（默认） | 找到有效壁纸 WorkerW | `worker_w`（`--wid`），图标不被遮挡 |
| **RaisedProgman** | Progman 带 `WS_EX_NOREDIRECTIONBITMAP` | Progman 子 WorkerW |
| **ShellHostLayered**（回退） | 无独立壁纸 WorkerW | `shell_host`，Z-order 在 DefView 下方 |

同类动态壁纸（飞火、Lively 等）共存策略：
- 启动灵境壁纸前/后：`suppress_competing_wallpaper_players()` 隐藏其他产品的 mpv/QWidget 等大窗口
- 停止灵境壁纸或退出应用：`restore_competing_wallpaper_players()` 恢复被隐藏的窗口
- 看门狗每 3s 重新压制仍可见的竞争窗口

## 三、静态壁纸（图片）实现

### 3.1 调用链路

```
用户点击「设为桌面」
  → LibraryPage.vue: applyWallpaper(id)
    → wallpaperStore.setWallpaper(id)
      → invoke('set_wallpaper', { id })
        → Rust: wallpaper_engine::set_wallpaper()
          ├─ detect_desktop_layer_conflicts()   // 检测冲突（图片壁纸也会检测）
          ├─ stop_video_wallpaper()             // 停止 MPV
          ├─ hide_desktop_player_window()       // 隐藏 WebView 播放器
          └─ set_windows_wallpaper(&path)
              → SystemParametersInfoW(SPI_SETDESKWALLPAPER, ...)
        ← 返回 { conflicts: [...] }
      → 有冲突时显示 warning toast
```

### 3.2 Windows API 调用

代码位置：[src-tauri/src/wallpaper_engine.rs](../src-tauri/src/wallpaper_engine.rs)（`set_windows_wallpaper`）

```rust
SystemParametersInfoW(
    SPI_SETDESKWALLPAPER,  // 0x0014 — 设置桌面壁纸
    0,
    Some(path_wide_str),   // 壁纸文件宽字符路径
    SPIF_UPDATEINIFILE     // 写入注册表，重启后保持
        | SPIF_SENDCHANGE, // 广播 WM_SETTINGCHANGE，即时生效
);
```

### 3.3 支持的格式

- **JPG / JPEG** — Windows 原生支持
- **PNG** — Windows 8+ 原生支持
- **WebP** — Windows 10 21H2+（需系统编解码器）
- **BMP** — 所有版本支持

## 四、视频壁纸实现（MPV + 桌面嵌入）

### 4.1 调用链路

```
用户点击「设为桌面」（视频壁纸）
  → LibraryPage.vue: applyWallpaper(id)
    → wallpaperStore.setWallpaper(id)
      → invoke('set_wallpaper', { id })
        → Rust: wallpaper_engine::set_wallpaper()
          ├─ detect_desktop_layer_conflicts()
          ├─ hide_desktop_player_window()
          └─ run_on_main_thread:
              video_player::start_video_wallpaper()
                ├─ desktop_core::setup_desktop_layer()
                ├─ suppress_competing_wallpaper_players() // 隐藏飞火等同类壁纸
                ├─ resolve_attach_mode() + wid_target()
                ├─ enumerate_monitors() → 每屏启动一个 MPV
                │     mpv --wid={target} --geometry={w}x{h}+{x}+{y} ...
                ├─ wait_for_mpv_window() → position_player_in_wallpaper_worker()
                ├─ ensure_desktop_zorder()
                └─ start_desktop_watchdog()   // 3 秒轮询恢复
        ← 返回 { conflicts: [...] }
      → 成功 toast + 冲突 warning toast
```

### 4.2 MPV 启动参数

代码位置：[src-tauri/src/video_player.rs](../src-tauri/src/video_player.rs)（`mpv_base_args`）

| 参数 | 作用 |
|------|------|
| `--wid={HWND}` | 将 MPV 窗口嵌入指定桌面宿主 |
| `--geometry={w}x{h}+{x}+{y}` | 铺满对应显示器区域 |
| `--loop-file=inf` | 无限循环 |
| `--hwdec=auto-safe` | 硬件解码 |
| `--vo=gpu --gpu-context=win` | GPU 渲染 |
| `--no-border --panscan=1.0` | 无边框、填充裁切 |
| `--mute=yes` | 静音 |
| `--cursor-autohide=always` | 隐藏鼠标 |

MPV 可执行文件查找顺序：`{app}/bin/mpv/mpv.exe` → `{app}/mpv.exe` → `PATH` 中的 `mpv.exe`。

### 4.3 多显示器

```
虚拟桌面 3840×1080（双屏 1920×1080 + 1920×1080）
  MPV[0] --geometry=1920x1080+0+0    → 左屏
  MPV[1] --geometry=1920x1080+1920+0  → 右屏
```

两个 MPV 进程共享同一个 `--wid` 宿主（壁纸 WorkerW），各自定位到不同显示器矩形。

### 4.4 桌面看门狗

`start_desktop_watchdog()` 每 3 秒检查：

| 条件 | 动作 |
|------|------|
| 壁纸 WorkerW 丢失或隐藏 | `reattach_if_running()` 重新定位 MPV |
| MPV 窗口不可见 | 同上 |
| 正常 | `refresh_icon_zorder()` 仅刷新图标层，避免闪屏 |

看门狗会周期性调用 `suppress_desktop_layer_interference()` 压制仍可见的竞争窗口。

### 4.5 退出清理

应用退出（`RunEvent::Exit`）或切换静态壁纸时：

1. `stop_desktop_watchdog()`
2. `child.kill()` + `taskkill /F /T /PID` 终止所有 MPV 进程

### 4.6 视频格式支持

依赖 MPV 与系统编解码器：

| 格式 | 容器 | 编码 | 支持情况 |
|------|------|------|:--:|
| **MP4** | `.mp4` | H.264 / H.265 | ✅ 推荐 |
| **WebM** | `.webm` | VP8 / VP9 | ✅ |
| **MKV** | `.mkv` | 多种 | ✅ 取决于已安装解码器 |

## 五、第三方桌面工具与同类壁纸共存

桌面整理类软件（腾讯桌面整理等）和飞火等动态壁纸会在桌面层插入大窗口，遮挡灵境壁纸。

### 5.1 检测（`detect_desktop_layer_conflicts`）

仍用于上报冲突信息（进程 / 全屏 `TXMiniSkin` 等），供前端提示。

### 5.2 自动处理（`suppress_desktop_layer_interference`）

视频壁纸启动时、看门狗周期内执行；停止壁纸或退出应用时 `restore_desktop_layer_interference` 恢复。

| 目标 | 条件 | 行为 |
|------|------|------|
| 飞火 / Lively 等 | 类名 mpv/glfw/QWidget 等，面积 ≥ 25% 屏 | `SW_HIDE` 临时隐藏 |
| 腾讯全屏皮肤 | `TXMiniSkin` 且面积 ≥ **70%** 虚拟桌面 | `SW_HIDE` 临时隐藏 |
| 腾讯栅栏/格子 | 小面积 `TXMiniSkin` | **不隐藏**，保留整理 UI |

### 5.3 用户提示

冲突说明在**首次启动向导**（快速上手步骤）中展示，应用壁纸时不再弹出 toast。

## 六、全屏检测与自动暂停

### 6.1 检测原理

代码位置：[src-tauri/src/wallpaper_engine.rs](../src-tauri/src/wallpaper_engine.rs)（`detect_fullscreen_windows`）

```
每隔 3 秒（App.vue 轮询）:
  GetForegroundWindow()
    → GetWindowRect(hwnd)
    → MonitorFromWindow(hwnd) → GetMonitorInfoW(monitor)
    → 窗口宽高 >= 显示器宽高 - 50px？
        YES → 判定全屏
        NO  → 非全屏
```

### 6.2 暂停链路

```
Rust: is_fullscreen_app_running() → bool
  → wallpaperStore.checkFullscreen()
    → if (settings.pauseOnFullscreen)
        → isVideoPlaying = !isFullscreen
```

> 注：当前视频由 MPV 独立进程播放，全屏暂停状态主要供 UI / 托盘展示；后续可对接 MPV IPC 实现真正暂停解码。

## 七、壁纸库数据管理

### 7.1 存储结构

```
{app_data_dir}/
├── wallpapers/
│   ├── wp_18d4f2a3_my-wallpaper.jpg
│   ├── wp_18d4f2b4_video-bg.mp4
│   └── ...
└── library.json
```

### 7.2 元数据格式

```json
{
  "wallpapers": [
    {
      "id": "wp_18d4f2a3",
      "filename": "wp_18d4f2a3_my-wallpaper.jpg",
      "path": "C:\\Users\\...\\wallpapers\\wp_18d4f2a3_my-wallpaper.jpg",
      "mediaType": "video",
      "format": "mp4",
      "width": 1920,
      "height": 1080,
      "fileSize": 5242880,
      "source": "local",
      "createdAt": "1718236800"
    }
  ]
}
```

### 7.3 操作流程

| 操作 | 流程 |
|------|------|
| **导入** | 复制文件到 `wallpapers/` → 生成唯一 ID → 写入 `library.json` |
| **删除** | 删除文件 → 从 `library.json` 移除条目 |
| **导出** | `fs::copy` 到目标路径 |
| **列出** | 读取 `library.json` 反序列化返回 |
| **应用** | 按 `mediaType` 分流：图片 → Windows API；视频 → MPV 嵌入 |

## 八、通信机制

### 8.1 Vue → Rust（命令）

```
Vue: invoke('set_wallpaper', { id })
  ↓
Rust: set_wallpaper() → SetWallpaperResult { conflicts }
```

### 8.2 Rust → Vue（事件）

```
Rust: app.emit("wallpaper-changed", { type, path, id, engine: "mpv" })
  ↓
```

## 九、性能考量

| 场景 | CPU 占用目标 | 实现方式 |
|------|:--:|------|
| **静态壁纸** | < 0.5% | Windows 原生管理，应用零渲染 |
| **视频壁纸（播放中）** | < 3% | MPV `--hwdec=auto-safe` 硬件解码 |
| **视频壁纸（看门狗空闲）** | 极低 | 仅 3 秒一次 HWND 探测 |
| **无壁纸（仅主窗口）** | < 1% | Vue 响应式 + Tauri WebView |

## 十、限制与已知边界

| 限制 | 说明 |
|------|------|
| **仅 Windows** | 桌面层嵌入依赖 Win32 API；macOS / Linux 未实现 |
| **需安装 MPV** | 未内置 mpv.exe 时启动失败，需用户安装或放到 `bin/mpv/` |
| **第三方桌面整理** | 全屏皮肤临时隐藏，退出后恢复；栅栏保留 |
| **视频无音频** | `--mute=yes`，桌面壁纸不需要声音 |
| **GIF 按静态图片处理** | 设为 Windows 桌面背景时 GIF 只显示第一帧 |
| **全屏暂停未接 MPV IPC** | 状态位已预留，实际暂停解码待后续接入 |
| **WebView 播放器未用于视频** | `DesktopPlayer.vue` 保留供 HTML 壁纸，当前视频走 MPV |
