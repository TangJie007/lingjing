# 灵境（LingScape）动态桌面实现原理

> 文档版本：1.0.0 | 对应代码版本：Phase 2（壁纸引擎）| 更新日期：2026-06-13

---

## 一、架构总览

灵境的动态桌面系统采用 **双窗口架构**，将"应用主界面"与"桌面壁纸渲染层"物理隔离：

```
┌──────────────────────────────────────────────────┐
│  桌面图标层（Windows Shell）                       │
├──────────────────────────────────────────────────┤
│  桌面播放器窗口（WebviewWindow, always_on_bottom）  │  ← 视频壁纸渲染层
│  · z-index: 桌面图标之下                          │
│  · 全屏尺寸、无边框、无任务栏                       │
├──────────────────────────────────────────────────┤
│  主窗口（灵境 LingScape 应用界面）                  │  ← 用户交互层
│  · 壁纸库浏览、AI 创作、设置                       │
│  · 无边框窗口，自定义标题栏                        │
└──────────────────────────────────────────────────┘
```

### 关键设计决策

| 决策 | 说明 |
|------|------|
| **双窗口而非单窗口** | 主窗口有标题栏、侧边栏等 chrome，不能直接做壁纸层。独立桌面播放器窗口专门负责渲染，与主窗口生命周期解耦。 |
| **静态壁纸走 Windows API** | 图片壁纸直接用 `SystemParametersInfoW(SPI_SETDESKWALLPAPER)` 设置，交给 Windows Shell 管理，零 CPU 开销。 |
| **视频壁纸走 WebView 渲染** | Windows 原生不支持视频桌面背景，通过一个 `always_on_bottom` 的透明 WebView 窗口嵌入 `<video>` 标签播放。 |
| **Rust 管理窗口，Vue 管理渲染** | 窗口的创建/显示/隐藏由 Rust 端（Tauri API）控制；视频播放、暂停、循环由 Vue 组件内的 `<video>` 元素控制。两端通过 Tauri 事件系统通信。 |

## 二、静态壁纸（图片）实现

### 2.1 调用链路

```
用户点击「设为桌面」
  → LibraryPage.vue: applyWallpaper(id)
    → wallpaperStore.setWallpaper(id)
      → invoke('set_wallpaper', { id })
        → Rust: wallpaper_engine::set_wallpaper()
          → set_windows_wallpaper(&path)
            → SystemParametersInfoW(SPI_SETDESKWALLPAPER, ...)
```

### 2.2 Windows API 调用

代码位置：[src-tauri/src/wallpaper_engine.rs:318-341](src-tauri/src/wallpaper_engine.rs#L318-L341)

```rust
// 核心：调用 Windows 系统 API 设置桌面壁纸
SystemParametersInfoW(
    SPI_SETDESKWALLPAPER,  // 0x0014 — 设置桌面壁纸
    0,                      // 未使用
    Some(path_wide_str),    // 壁纸文件的宽字符路径
    SPIF_UPDATEINIFILE      // 0x0001 — 写入注册表，重启后保持
        | SPIF_SENDCHANGE,  // 0x0002 — 广播 WM_SETTINGCHANGE，即时生效
);
```

### 2.3 支持的格式

- **JPG / JPEG** — Windows 原生支持
- **PNG** — Windows 8+ 原生支持
- **WebP** — Windows 10 21H2+ 支持（需系统编解码器）
- **BMP** — 所有版本支持

### 2.4 切换回静态壁纸时

当用户选择静态壁纸时，系统会：
1. 调用 `hide_desktop_player_window()` 隐藏视频播放器窗口
2. 调用 `set_windows_wallpaper()` 设置 Windows 桌面背景
3. 桌面图标正常显示在壁纸之上

## 三、视频壁纸实现

### 3.1 调用链路

```
用户点击「设为桌面」（视频壁纸）
  → LibraryPage.vue: applyWallpaper(id)
    → wallpaperStore.setWallpaper(id)
      → invoke('set_wallpaper', { id })
        → Rust: wallpaper_engine::set_wallpaper()
          ├─ ensure_desktop_player_window(&app)   // 创建/显示播放器窗口
          └─ app.emit("wallpaper-changed", {...})  // 通知前端切换视频源
              ↓ (Tauri 事件系统)
            DesktopPlayer.vue: listen('wallpaper-changed')
              → videoPath.value = event.payload.path  // 更新 <video src>
                → <video> 自动播放（autoplay + loop）
```

### 3.2 桌面播放器窗口的创建

代码位置：[src-tauri/src/wallpaper_engine.rs:398-423](src-tauri/src/wallpaper_engine.rs#L398-L423)

```rust
WebviewWindowBuilder::new(app, "desktop-player", WebviewUrl::App("/#/desktop-player".into()))
    .title("灵境 桌面播放器")
    .inner_size(screen_width, screen_height)  // 覆盖整个主显示器
    .position(0.0, 0.0)                       // 左上角对齐
    .decorations(false)                        // 无标题栏
    .resizable(false)                          // 不可调整大小
    .always_on_bottom(true)                    // ⭐ 始终在桌面图标之下
    .skip_taskbar(true)                        // 不在任务栏显示
    .visible(true)                             // 创建后立即显示
    .transparent(true)                         // 背景透明（无视频时透出桌面）
    .build()
```

### 3.3 窗口层级关系

```
z-order（从高到低）:
  ┌─────────────────────┐
  │  其他应用窗口         │  z: normal
  │  桌面图标             │  z: desktop (SHELLDLL_DefView)
  │  ─ ─ ─ ─ ─ ─ ─ ─ ─ │
  │  灵境桌面播放器窗口   │  z: bottom-most (always_on_bottom)
  │  灵境主窗口           │  z: normal（用户操作时提到前台）
  └─────────────────────┘
```

`always_on_bottom(true)` 确保播放器窗口始终位于桌面图标层之下、原始桌面背景之上，用户看到的视觉效果等同于"视频替代了静态桌面背景"。

### 3.4 视频渲染（前端）

代码位置：[src/views/DesktopPlayer.vue](src/views/DesktopPlayer.vue)

```html
<div class="desktop-player">          <!-- 全屏容器，z-index: -999, pointer-events: none -->
  <video
    src="asset://localhost/{path}"    <!-- Tauri 本地资源协议 -->
    autoplay                           <!-- 自动播放 -->
    loop                               <!-- 循环播放 -->
    muted                              <!-- 静音（桌面壁纸不需要声音） -->
    playsinline                        <!-- 内联播放（不进入全屏模式） -->
  />
</div>
```

关键 CSS：
```css
.desktop-player {
  position: fixed;    inset: 0;
  z-index: -999;                  /* 低于所有正常元素 */
  pointer-events: none;           /* 鼠标事件穿透，不影响桌面图标操作 */
}
.desktop-video {
  object-fit: cover;              /* 等比例填充，不拉伸变形 */
  min-width: 100%; min-height: 100%;
}
```

### 3.5 视频格式支持

依赖系统已安装的视频编解码器（Windows 10+ 内置支持）：

| 格式 | 容器 | 编码 | 支持情况 |
|------|------|------|:--:|
| **MP4 (H.264)** | `.mp4` | AVC/H.264 | ✅ Windows 10+ 内置 |
| **WebM (VP8/VP9)** | `.webm` | VP8/VP9 | ✅ Windows 10 1809+ |

## 四、全屏检测与自动暂停

### 4.1 检测原理

代码位置：[src-tauri/src/wallpaper_engine.rs:352-388](src-tauri/src/wallpaper_engine.rs#L352-L388)

```
每隔 3 秒（主窗口）/ 2 秒（桌面播放器窗口）:
  GetForegroundWindow()                     // 获取当前前台窗口句柄
    → GetWindowRect(hwnd)                   // 获取窗口尺寸
    → MonitorFromWindow(hwnd)               // 获取窗口所在显示器
    → GetMonitorInfoW(monitor)              // 获取显示器尺寸
    → 比对：窗口宽高 >= 显示器宽高 - 50px？
        YES → 判定为全屏 → 暂停视频
        NO  → 非全屏 → 恢复视频
```

### 4.2 容错设计

- 50px 的容差阈值：避免任务栏自动隐藏、窗口边框等边界情况误判
- `GetForegroundWindow()` 返回 null → 直接返回 false（安全降级）
- `GetWindowRect` 失败 → 返回 false（安全降级）
- `GetMonitorInfoW` 失败 → 返回 false（安全降级）

### 4.3 暂停/恢复链路

```
Rust: is_fullscreen_app_running() → bool
  → wallpaperStore.checkFullscreen()
    → if (settings.pauseOnFullscreen)
        → setFullscreenPaused(isFullscreen)
          → isVideoPlaying = !isFullscreen
            → DesktopPlayer.vue: watch(isVideoPlaying)
              → video.pause() 或 video.play()
```

用户在设置中关闭「全屏时暂停」开关后，全屏检测结果不再影响播放状态。

## 五、壁纸库数据管理

### 5.1 存储结构

```
{app_data_dir}/
├── wallpapers/                    # 壁纸文件目录
│   ├── wp_18d4f2a3_my-wallpaper.jpg
│   ├── wp_18d4f2b4_video-bg.mp4
│   └── ...
└── library.json                   # 元数据索引
```

### 5.2 元数据格式

```json
{
  "wallpapers": [
    {
      "id": "wp_18d4f2a3",
      "filename": "wp_18d4f2a3_my-wallpaper.jpg",
      "path": "C:\\Users\\...\\wallpapers\\wp_18d4f2a3_my-wallpaper.jpg",
      "mediaType": "image",
      "format": "jpg",
      "width": 1920,
      "height": 1080,
      "fileSize": 524288,
      "source": "local",
      "createdAt": "1718236800",
      "prompt": null,
      "plan": null,
      "model": null,
      "cost": null
    }
  ]
}
```

### 5.3 操作流程

| 操作 | 流程 |
|------|------|
| **导入** | 复制文件到 `wallpapers/` → 生成唯一 ID → 写入 `library.json` |
| **删除** | 删除文件 → 从 `library.json` 移除条目 |
| **导出** | 读取 `library.json` 找到路径 → `fs::copy` 到目标位置 |
| **列出** | 直接读取 `library.json` 反序列化返回 |

## 六、通信机制

### 6.1 Rust → Vue（事件）

```
Rust: app.emit("wallpaper-changed", { type, path, id })
  ↓ Tauri 事件系统（IPC）
Vue: listen<{type, path, id}>('wallpaper-changed', callback)
```

### 6.2 Vue → Rust（命令）

```
Vue: invoke('set_wallpaper', { id })
  ↓ Tauri IPC（JSON 序列化）
Rust: #[tauri::command] fn set_wallpaper(app, id)
```

### 6.3 命令清单

| 命令名 | 方向 | 用途 |
|--------|------|------|
| `list_wallpapers` | Vue → Rust | 获取壁纸列表 |
| `import_wallpaper` | Vue → Rust | 导入本地文件 |
| `delete_wallpaper` | Vue → Rust | 删除壁纸 |
| `export_wallpaper` | Vue → Rust | 导出壁纸 |
| `set_wallpaper` | Vue → Rust | 设置壁纸（触发桌面渲染） |
| `get_library_size` | Vue → Rust | 获取库占用空间 |
| `clear_library` | Vue → Rust | 清除全部壁纸 |
| `is_fullscreen_app_running` | Vue → Rust | 检查全屏状态 |
| `wallpaper-changed` | Rust → Vue | 通知视频源变更 |

## 七、性能考量

| 场景 | CPU 占用目标 | 实现方式 |
|------|:--:|------|
| **静态壁纸** | < 0.5% | Windows 原生管理，应用进程零渲染 |
| **视频壁纸（播放中）** | < 3% | `<video>` 标签硬件解码，WebView 合成 |
| **视频壁纸（全屏暂停）** | < 0.5% | 调用 `video.pause()`，解码器停止工作 |
| **无壁纸（仅主窗口）** | < 1% | 仅 Vue 响应式系统开销 |

## 八、限制与已知边界

| 限制 | 说明 | 计划 |
|------|------|:--:|
| **仅主显示器** | 桌面播放器窗口覆盖主显示器，多显示器场景下其他屏幕不受影响 | V1.5 支持多显示器 |
| **仅 Windows** | macOS/Linux 使用不同的桌面壁纸 API，当前未实现 | V3.0+ |
| **视频无音频** | 桌面壁纸不需要声音，`<video muted>` | 设计如此 |
| **GIF 按静态图片处理** | 设为 Windows 桌面背景时 GIF 只显示第一帧 | V1.5 探索 WebView GIF 播放 |
| **Tauri asset 协议** | 视频通过 `asset://localhost/{path}` 加载，需 Tauri 2.x 安全配置允许 | — |
