# 多平台API管理

> **模块**：API Key管理 | **优先级**：P1 | **状态**：草稿 | **版本**：v2.0.0
>
> **创建**：2026-06-15 | **最后更新**：2026-06-15

---

## 📝 功能描述

V2 在 V1 火山引擎基础上新增 DeepSeek（第一步）和快手可灵（第二步视频）两个平台。

### 详细说明

每平台独立卡片，显示 Logo + 名称 + Key 输入框 + 状态指示灯 + 测试连接按钮。 生成界面新增「生成模式」下拉：图片模式（Seedream）/ 视频模式（可灵/即梦）。 用户可配置第一步偏好模型 + 第二步偏好模型，系统记住上次选择。

### 功能范围

DeepSeek 接入、可灵接入、生成模式下拉、模型偏好记忆
