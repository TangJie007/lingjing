# 壁纸播放调节

> **模块**：壁纸播放引擎 | **优先级**：P2 | **状态**：草稿 | **版本**：v2.0.0
>
> **创建**：2026-06-15 | **最后更新**：2026-06-15

---

## 📝 功能描述

支持对视频壁纸进行播放速度、亮度、饱和度、对比度的实时调节。通过 GPU Shader / DirectX 滤镜实现，不修改源文件。

### 详细说明

播放速度支持 0.5x / 1x / 1.5x / 2x，默认 1x。 亮度、饱和度、对比度各支持 -50% ~ +50% 范围调节，默认 0。 所有调节实时预览，不修改源文件。

### 功能范围

播放速度调节、亮度调节、饱和度调节、对比度调节
