# 退出恢复原始桌面

> **模块**：基础设置 | **优先级**：P0 | **状态**：草稿 | **版本**：v2.0.0
>
> **创建**：2026-06-15 | **最后更新**：2026-06-15

---

## 📝 功能描述

当用户关闭/退出灵境时，自动将 Windows 桌面壁纸恢复为进入灵境之前的原始壁纸，不留下任何残留。

### 详细说明

启动时读取并备份当前 Windows 壁纸路径和显示方式到 %AppData%\LingScape\backup\。 正常退出时恢复原始壁纸并清除快照；关闭窗口（最小化到托盘）时不恢复。 系统关机/重启时尝试恢复。启动时检测是否有未恢复的快照，若有则弹出提示询问是否恢复。 设置中提供「退出时恢复原始桌面」开关（默认开启）和「退出前询问确认」开关（默认关闭）。

### 功能范围

原始壁纸快照备份、正常退出恢复、崩溃恢复检测、设置开关

## ✅ 验收标准

| ID | 验收标准 | 预期结果 | 测试方式 |
|----|----------|----------|----------|
| AC-001 | 启动时备份原始壁纸 | Given 用户启动灵境，When 应用初始化，Then 读取并备份当前 Windows 壁纸路径和显示方式到 %AppData% | 自动 |
| AC-002 | 正常退出恢复 | Given 用户从托盘退出或点击关闭按钮，When 退出应用，Then 恢复原始壁纸并清除快照 | 自动 |
| AC-003 | 最小化不恢复 | Given 用户关闭窗口（最小化到托盘），When 窗口关闭，Then 壁纸继续播放，不恢复原始壁纸 | 自动 |
| AC-004 | 关机时恢复 | Given 系统关机/重启，When Windows 会话结束，Then 尝试恢复原始壁纸 | 自动 |
| AC-005 | 崩溃恢复检测 | Given 灵境上次异常退出，When 重新启动，Then 检测到未恢复快照，弹出提示询问是否恢复 | 自动 |
| AC-006 | 退出恢复开关 | Given 用户在设置页，When 切换「退出时恢复原始桌面」开关，Then 默认开启，关闭后退出不恢复 | 自动 |
| AC-007 | 退出确认开关 | Given 用户在设置页，When 开启「退出前询问确认」，Then 每次退出弹出确认对话框 | 自动 |
