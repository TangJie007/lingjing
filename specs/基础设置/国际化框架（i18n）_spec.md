>
> **创建**：2026-06-12 | **最后更新**：2026-06-12

---

## 📝 功能描述

预留多语言能力，所有UI文案统一走i18n key，本期实现中文简体（zh-CN），预留英文（en）骨架

### 详细说明

国际化框架是应用的架构基础，要求所有面向用户的文本（UI标签、提示、错误信息、Toast、 菜单项、向导文案）统一使用 i18n key 引用，禁止在业务代码中硬编码中文字符串。 本期完整实现中文简体（zh-CN），预留英文（en）翻译文件骨架。后续新增语言只需添加 翻译文件，无需修改业务代码。语言切换支持热切换（无需重启应用）。数字和日期格式化 走标准 Intl API。

### 功能范围

i18n 初始化与语言切换、zh-CN 完整翻译、en 骨架预留、Intl 格式化封装、语言检测

## ✅ 验收标准

| ID | 验收标准 | 预期结果 | 测试方式 |
|----|----------|----------|----------|
| AC-001 | 无硬编码中文 | Given 应用启动，When 检查所有 UI 文案（菜单/按钮/提示/错误/Toast/向导），Then 无硬编码中文字符串，全部通过 i18n key 引用 | 自动 |
| AC-002 | zh-CN 完整覆盖 | Given 语言设为中文简体，When 遍历所有页面和组件，Then 所有文本正确显示为简体中文，无缺失 key 导致的占位符 | 自动 |
| AC-003 | en 骨架文件存在 | Given 检查 i18n 翻译目录，When 查看 locales/，Then 存在 zh-CN.json（完整）和 en.json（骨架，含所有 key 但值为英文占位） | 自动 |
| AC-004 | 语言热切换 | Given 运行时切换语言，When 调用 setLocale()，Then 所有已渲染 UI 立即更新为新语言，无需刷新页面或重启 | 自动 |
| AC-005 | 缺失 key 回退 | Given 当前语言缺少某个 key 的翻译，When 渲染该 key，Then 回退到 zh-CN 默认值并 console.warn 提示 | 自动 |
| AC-006 | 格式化方法 | Given 需要格式化数字/日期/货币，When 调用 i18n 格式化方法，Then 按当前语言区域正确格式化（如 zh-CN 日期为 2026年6月12日） | 自动 |
