# 壁纸库视觉化升级

> **模块**：壁纸库管理 | **优先级**：P0 | **状态**：草稿 | **版本**：v2.0.0
>
> **创建**：2026-06-15 | **最后更新**：2026-06-15

---

## 📝 功能描述

V1 壁纸库以列表/文字为主，缺乏直观预览。V2 全面升级为卡片缩略图网格模式，所有类型壁纸都必须有图片展示。

### 详细说明

支持网格/列表双视图切换、三档卡片尺寸（大/中/小）、hover 动态预览（静音）。 MP4/WebM 导入时自动截取第 0.5 秒帧生成 WebP 缩略图，GIF 截取第一帧。 默认按导入时间降序排列，支持按名称、文件大小、最近使用排序。 AI 生成壁纸的入库时间 = 生成完成时间，与导入壁纸统一排序。

### 功能范围

卡片缩略图网格、缩略图自动生成、hover 动态预览、多维度排序、视图切换

## ✅ 验收标准

| ID | 验收标准 | 预期结果 | 测试方式 |
|----|----------|----------|----------|
| AC-001 | 卡片网格默认展示 | Given 用户打开壁纸库，When 查看壁纸列表，Then 以卡片网格展示，每张卡片包含缩略图、名称、来源标识 | 自动 |
| AC-002 | 网格/列表视图切换 | Given 用户在壁纸库，When 切换网格/列表视图，Then 切换后保持用户偏好 | 自动 |
| AC-003 | 卡片尺寸切换 | Given 用户在壁纸库，When 切换大/中/小卡片尺寸，Then 卡片尺寸实时变化，默认中号 180×140px | 自动 |
| AC-004 | MP4/WebM 缩略图自动生成 | Given 用户导入 MP4/WebM 文件，When 导入完成，Then 自动截取第 0.5 秒帧生成 WebP 缩略图，后台线程不阻塞 UI | 自动 |
| AC-005 | GIF 缩略图自动生成 | Given 用户导入 GIF 文件，When 导入完成，Then 自动截取第一帧作为缩略图 | 自动 |
| AC-006 | 动态壁纸类型角标 | Given 壁纸库中有动态壁纸，When 查看卡片，Then 右上角显示类型角标（▶ GIF / 🎬 MP4 / 🎬 WebM） | 自动 |
| AC-007 | hover 动态预览 | Given 用户 hover 动态壁纸卡片 0.5s，When 停留，Then GIF/MP4 自动播放预览（静音），移出停止 | 自动 |
| AC-008 | 关闭 hover 预览 | Given 用户在设置中关闭 hover 自动预览，When hover 卡片，Then 不自动播放 | 自动 |
| AC-009 | 默认排序规则 | Given 用户打开壁纸库，When 查看列表，Then 默认按导入时间降序排列（最新在前） | 自动 |
| AC-010 | 多维度排序 | Given 用户在壁纸库，When 切换排序方式，Then 支持按名称、文件大小、最近使用排序 | 自动 |
| AC-011 | AI 壁纸排序统一 | Given 壁纸库中有 AI 生成壁纸，When 按导入时间排序，Then AI 生成壁纸的入库时间 = 生成完成时间，与导入壁纸统一排序 | 自动 |
