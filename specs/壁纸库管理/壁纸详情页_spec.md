# 壁纸详情页

> **模块**：壁纸库管理 | **优先级**：P0 | **状态**：草稿 | **版本**：v2.0.0
>
> **创建**：2026-06-15 | **最后更新**：2026-06-15

---

## 📝 功能描述

点击任意壁纸卡片进入全屏或侧边栏详情页，展示大图预览 + 完整元数据 + 操作按钮。

### 详细说明

AI 生成壁纸额外展示原始描述、优化 Prompt、风格标签、色调色块、AI 模型信息。 动态壁纸在详情页自动播放（静音），有播放进度条 + 暂停/播放控制。 支持键盘快捷键：空格=暂停/播放，左右箭头=上/下一张壁纸，Esc=返回。

### 功能范围

大图预览、元数据面板、AI 方案信息展示、动态播放控制、键盘快捷键

## ✅ 验收标准

| ID | 验收标准 | 预期结果 | 测试方式 |
|----|----------|----------|----------|
| AC-001 | 详情页布局 | Given 用户点击壁纸卡片，When 进入详情页，Then 左侧大图预览（16:9），右侧元数据面板 | 自动 |
| AC-002 | 基础元数据展示 | Given 用户在详情页，When 查看信息面板，Then 显示名称、类型、分辨率、文件大小、导入/生成时间 | 自动 |
| AC-003 | AI 方案信息展示 | Given 用户查看 AI 生成壁纸详情，When 查看信息面板，Then 额外展示原始描述、优化 Prompt、风格标签、色调色块、AI 模型 | 自动 |
| AC-004 | 复制 Prompt 和重新生成 | Given 用户在 AI 壁纸详情页，When 点击操作按钮，Then 支持「复制 Prompt」和「用此方案重新生成」 | 自动 |
| AC-005 | 动态壁纸自动播放 | Given 用户进入动态壁纸详情页，When 页面加载，Then MP4/GIF/WebM 自动播放（静音），无限循环 | 自动 |
| AC-006 | 播放控制栏 | Given 用户在动态壁纸详情页，When 查看播放控制，Then 有播放进度条 + 暂停/播放控制 | 自动 |
| AC-007 | 键盘快捷键 | Given 用户在详情页，When 按键，Then 空格=暂停/播放，左右箭头=上/下一张壁纸，Esc=返回 | 自动 |
