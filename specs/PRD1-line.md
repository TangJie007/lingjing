# PRD 一行总结

> 来源：AI动态桌面_V1_PRD.md | 版本：1.4.0 | 生成时间：2026-06-12

| ID | 模块 | 功能 | 一句话 |
|----|------|------|--------|
| ST-001 | 系统托盘 | 托盘最小化与右键菜单 | 最小化到托盘，右键菜单提供暂停/切换/打开/退出 |
| SET-005 | 基础设置 | 国际化框架（i18n） | 所有 UI 文案统一走 i18n key，本期 zh-CN 完整 + en 骨架预留，支持热切换 |
| SET-001 | 基础设置 | 通用设置 | 开机自启开关 + 语言切换（本期中文简体，通过 i18n 热切换） |
| OB-001 | 首次启动向导 | 欢迎页与品牌动画 | 首次启动展示品牌动画+产品定位，3秒后可进入下一步 |
| WP-001 | 壁纸播放引擎 | 静态图片壁纸播放 | JPG/PNG/WebP 设为桌面，支持填充/适应/拉伸/平铺，CPU<0.5% |
| WP-003 | 壁纸播放引擎 | 全屏检测自动暂停 | 检测全屏 3D 应用自动暂停视频解码，退出全屏自动恢复 |
| WP-002 | 壁纸播放引擎 | 视频壁纸播放 | MP4/WebM 循环播放，1080P/30fps，CPU<3% |
| WL-001 | 壁纸库管理 | 本地壁纸管理 | 网格浏览/应用/删除/导出本地壁纸（JPG/PNG/WebP/MP4/WebM/GIF） |
| SET-003 | 基础设置 | 壁纸播放设置 | 播放帧率 30/60FPS + 缩放模式切换，实时生效 |
| SET-004 | 基础设置 | 性能与存储设置 | 全屏暂停开关 + 壁纸库上限 5GB + 清除缓存 |
| API-001 | API Key 管理 | API Key 配置与加密存储 | 火山引擎 Key 本地加密存储、掩码显示、粘贴自动去空格 |
| API-002 | API Key 管理 | API Key 有效性检测 | 发送最小请求验证 Key，🟢绿/🔴红/⚫灰 状态指示灯 |
| OB-002 | 首次启动向导 | 火山引擎注册引导 | 视频教程+注册链接+截图教程+Key 输入+连接诊断，2-5分钟 |
| OB-004 | 首次启动向导 | 跳过 API 配置的本地模式 | 跳过配置进入本地导入模式，顶部常驻 API 配置引导条 |
| AI-001 | AI 生成管线 | AI 意图分析与方案构建 | 文字描述+可选参考图→VL-LLM→优化英文 prompt+风格标签+色调+构图 |
| AI-003 | AI 生成管线 | 构建方案预览与确认 | 方案卡片展示 prompt/风格/色调，用户可编辑确认后再生成 |
| AI-002 | AI 生成管线 | 专业壁纸生成 | Seedream 4.0 生成 1/3/5 张变体，1080P/2K/4K，5-10秒 |
| WL-002 | 壁纸库管理 | AI 生成历史 | 记录每次生成的 prompt/构建方案/模型/时间/费用 |
| OB-003 | 首次启动向导 | 快速上手与一键生成 | 3 个预设描述+一键生成第一张壁纸，30-60秒完成 |
| API-003 | API Key 管理 | 多平台 API 管理 | V1 仅火山引擎卡片可用，DeepSeek/智谱/可灵灰色待扩展 |
| SET-002 | 基础设置 | API 默认值与生成配置 | 第一步模型/第二步模型/生成数量/分辨率默认值配置 |
